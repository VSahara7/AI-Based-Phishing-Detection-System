1. Problem & Motivation

The Problem

Scammers target victims through emails, text messages, and deceptive links daily.

Existing security tools mainly focus on English, leaving other languages vulnerable.

Research Gap

  • Lack of tools for regional scripts.
  • Unclear preprocessing steps in past studies.
  • Need for easy-to-use web implementations.
  • Very limited work on Nepali scam text.

3. How the System Works

Figure 1. System Flowchart

Step-by-Step Flow

  • User Submission: User pastes a suspicious email or message.
  • Flask Backend: Sends text to the NLP processing module.
  • Text Cleaning: Removes noise, formatting, and standardizes vocabulary.
  • Feature Extraction: Converts text to numerical values via TF-IDF.
  • Classifier: Flags input as either Scam or Legitimate.

4. Testing Methodology

Summary: We strictly separated training and testing data to prevent bias. Models were trained purely on training samples before being tested on unseen messages and integrated into a web tool.

11. User Web Application

Figure 4. Simple Web Dashboard built with Python and Flask

12. Known Limits & Next Steps

  • Hyperparameters were kept default rather than fine-tuned.
  • The final real-world test set was small (30 messages).
  • Future Work: Test advanced AI models like BERT and Transformers.
  • Future Work: Build a live browser extension for email apps.

13. Concluding Remarks

Combining simple text feature extraction with standard machine learning algorithms provides a fast and highly effective way to spot scams in English and Romanized Nepali, with Random Forest leading at 98.06% overall accuracy.

The misclassified Devanagari samples show that low-resource scripts require custom language processing tools and larger datasets in future updates.
