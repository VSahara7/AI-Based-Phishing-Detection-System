# AI-Based Phishing and Social Engineering Scam Detection System Using Machine Learning and Natural Language Processing

## Overview

This MSc dissertation project develops an AI-based system capable of detecting phishing and social engineering messages using Machine Learning and Natural Language Processing (NLP).

## Objectives

- Detect phishing emails and SMS messages
- Apply NLP preprocessing techniques
- Compare multiple machine learning algorithms
- Evaluate model performance using standard metrics
- Develop a simple web-based prediction system

## Technologies

- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit
- Matplotlib

## Project Structure

- `datasets/` – datasets used for training
- `src/` – preprocessing, training, and evaluation scripts
- `models/` – trained models
- `outputs/` – generated figures and results
- `app.py` – Streamlit application
